# Praxis — лендинг

Одностраничный лендинг AI-экосистемы для психологов.

## Файлы

- `index.html` — готовая страница (HTML + CSS в одном файле, без сборки). Открывается в браузере напрямую или публикуется через GitHub Pages.
- `tilda-block.html` — тот же контент для вставки в Tilda: блок **T123 — HTML-код** (раздел «Другое»), вставить весь код целиком. Весь CSS изолирован префиксом `.px`.

## Публикация на GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/ (root)`.
