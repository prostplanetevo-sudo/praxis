# Praxis — лендинг

Одностраничный лендинг AI-экосистемы для психологов и помогающих профессий. Статический сайт: HTML, CSS и немного JavaScript, без сборки и зависимостей. Фирменный стиль Praxis: логотип, цвета, шрифты Montserrat и Inter, светлая и тёмная тема (переключается автоматически по настройкам устройства).

Сайт: https://prostplanetevo-sudo.github.io/praxis/

## Что внутри

```
index.html              главная страница (весь контент)
404.html                страница «не найдено»
site.webmanifest        данные для закладок и «на главный экран»
robots.txt, sitemap.xml для поисковиков
favicon.svg / .ico, apple-touch-icon.png
.nojekyll               говорит GitHub Pages не обрабатывать сайт Jekyll
assets/
  css/style.css         все стили; цвета и размеры — в блоке :root вверху
  js/main.js            мобильное меню и тень шапки при прокрутке
  img/                  логотипы, символ, паттерны, og-image, иконки приложения
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save. После каждого коммита в `main` сайт обновляется за 1–2 минуты.

Все пути в проекте относительные, поэтому сайт одинаково работает на `prostplanetevo-sudo.github.io/praxis/` и на отдельном домене.

### Адрес сайта

Адрес `https://prostplanetevo-sudo.github.io/praxis/` прописан в `index.html` (canonical, og:url, og:image), `404.html`, `robots.txt` и `sitemap.xml`. Если сайт переедет на свой домен:

1. Добавьте в корень файл `CNAME` с одной строкой (например, `praxis.example`) и настройте DNS по инструкции GitHub.
2. Замените адрес во всех четырёх файлах:

```bash
grep -rl "prostplanetevo-sudo.github.io/praxis" . --exclude-dir=.git | xargs sed -i 's#https://prostplanetevo-sudo.github.io/praxis/#https://praxis.example/#g'
```

## Что менять при правках

| Что | Где |
|---|---|
| Контакты | `index.html`: поиск по `t.me/pgl13`, `praxi-s@inbox.ru`, `+7 916 181-41-82` / `+79161814182` |
| Тарифы и условия токенов | секция `id="price"` и вопрос «Что такое токены…» в блоке `id="faq"` |
| Цифры в верхней плашке | секция со статистикой сразу под первым экраном |
| Тексты вопросов и ответов | блок `id="faq"` (обычные `<details>`) |
| Цвета, скругления, шрифты | `assets/css/style.css`, блок `:root` (светлая тема) и `@media (prefers-color-scheme: dark)` (тёмная) |
| Превью для соцсетей | `assets/img/og-image.png` (1200×630) |

## Проверка перед рассылкой

- Откройте сайт на телефоне и на компьютере, проверьте якоря меню, кнопку «Написать в Telegram», почту и телефон.
- Проверьте цифры и утверждения на странице: «50 экспертов на платформе сегодня», «1 млн+ материалов» (целевой ориентир), «100% материалов проходят ручную модерацию», «модераторы с более чем 20-летним стажем», сравнение с комиссией агрегаторов 30–35%.
- Блок в первом экране («Клиентка, 34 года…») — иллюстрация интерфейса, не реальный диалог. Подпись «Пример интерфейса, иллюстрация» под ним оставьте.

## Локальный просмотр

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

Шрифты Montserrat и Inter подгружаются с Google Fonts; без интернета страница использует Arial.
